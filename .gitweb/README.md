## Static website based on staticjinja and bootstrap

I hope this will eventually become my new website.
It is currently built using the following tools:

* [staticjinja](http://staticjinja.readthedocs.org/en/latest/)

* [Jinja2](http://jinja.pocoo.org/)

* [Markdown](http://daringfireball.net/projects/markdown/syntax) via
  [jinja2_markdown](https://github.com/danielchatfield/jinja2_markdown)

* [bootstrap](http://getbootstrap.com/)
