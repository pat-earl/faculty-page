## Modules

* Built-in & Third Party modules
* `import`
  * Explicit import
* `import module as mod`
  * Explicit import by alias
* `from module import func1, func2`
  * Explicit import of contents
* `from module import *`
  * Implicit import of contents
  
## Standard Libraries

* *os* & *sys* - Interface with OS
* *math* & *cmath* - Mathematical functions 
* *itertools*
* *functools*
* *csv* & *json* - Create/Read JSON-formatted and CSV-formatted files
* *random* - Pseudorandom numbers
* *pickle* - Save and load objects from disk
