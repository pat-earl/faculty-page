title: CSC135 Homework Guidelines

## Requirements

* Unless otherwise stated in the handout, programming assignment submissions
that don't compile will receive a zero (0).
* Project Plans are required for the first two programs and program 4. You can 
download the template [here]
* All assignments are due by 11:59PM of the due date. Late submissions will be 
accepted for up to two (2) days, with a 10% penalty applied for each day. Any 
submissions received beyond that will not be accepted.

## Grading Criteria

* **Analysis and Design (10 Points):** The program submission must include a project plan document. [See a template here]((./project_plan.docx)
* **Style (20 Points):** 
  * The program must be documented according to the [Documentation Standards](https://www.kutztown.edu/Departments-Offices/A-F/ComputerScienceInformationTechnology/Documents/Student%20Resources/DocumentationStandard.pdf)
  * The program must be written in a structured form with appropriate indentation and white space.
  * Identifiers must have meaningful names.
* **Functions (20 Points):** After functions are covered, the program must make appropriate use of functions. Each function must be well defined and perform only one task.
* **Specification (50 Points):** The program must work properly according to the specification. Meaning it must solve the specified problem and produce correct results.
* *Note:* Before functions are covered, the Function criterion points will be divided evenly between the Analysis and Design/Style criteria.
