# **UNIX Commands**

Generally speaking, an instruction is executed by the user on the command line (or shell prompt). The user's shell will then process the command and run it.

Any output generated by the command will be displayed back to the user.

---

# **UNIX Command Syntax**

Commands can be made up of 3 parts:
1. Command Name
2. Options
   - These affect the output of a command
   - Typically a dash (`-`) followed by a letter.
3. Arguments
   - Tells the command what thing to work on (file, directory, etc.)

# **Special Characters**

- ``* ; | * ? ' " ` [ ] ( ) $ < > { } # / \ ! ~``

# **Combining Commands**

The introduction to process pipelines (`|`).

Use of the pipe allows for sending the *output* of one command to be *input* of the next. 

- `ls | wc -l`
