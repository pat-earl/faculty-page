## Description

### Part A

Below you'll find two different IPv4 address blocks, how many subnets are needed for each one, and how many hosts will be on each subnet. When calculating your subnet size, take into consideration the growth of the subnet due to increases in the number of hosts.

For each block you'll need to provide the following:

1. Your justification for picking the subnet mask you did. Explain your estimated growth in the number of hosts.
2. The subnet address w/ CIDR notation for each individual subnet. 

**Scenario 1:**

Your company has been assigned the following address block: `210.12.12.0/24`. You will need to subnet this address block out to handle the number of hosts in the following departments:

- **Human Resources** - 25 Hosts
- **Finance** - 50 Hosts
- **Information Technology** - 25 Hosts
- **Customer Service** - 75 Hosts

**Scenario 2:**

The University you work for is planning for a network re-design in the summer. The school has been assigned the following
address block: `156.16.0.0/16`. Each building will be an individual subnet, containing the following number of hosts:

- **Administration** - 75 Hosts
- **Main Academic Building** - 200 Hosts
- **Secondary Academic Building** - 100 Hosts
- **Dorm A** - 300 Hosts
- **Dorm B** - 150 Hosts

### Part B

For these two IP Addresses (`128.2.32.0/20` and `24.130.0.0/15`), figure out the following:

1. Maximum number of hosts on the network
2. Subnet Mask
3. CIDR Network IP Address
4. First Host IP Address
5. Last Host IP Address
