## Description

Systems integration is a process of connecting separate computing systems (or software apps) into a
single larger systems. Essentially allowing each to work together [^1]. For Example: Consider a company's
applications to handle payroll and accounting. While the systems were developed separately in the past,
they need to be brought together due to changing requirements. 

There are three main methodologies when it comes to systems integration: Vertical, Horizontal, and Star.
