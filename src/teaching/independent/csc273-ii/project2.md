## Description

The next project is to implement Google's OAuth single sign on as account management on a simple website. 
This project will be creating a process map of how that will work.

Your website will consist of *two* web pages. First one is used to login to an account
and the second page is only accessible by an authorized user (meaning they're logged in).

You'll be creating a [Process Map](https://creately.com/blog/diagrams/process-mapping-guide/) 
(you may know these as a flowchart) of the steps for when a user signs into an account
using Google OAuth. You'll be specificity creating a [swimlane diagram](https://www.lucidchart.com/pages/tutorial/swimlane-diagram),
Chapter 4 of the *Modern ERP* textbook gives specific examples.

The three roles in this case are going to be the *User*, *Your Website*, and *Google's Services*. 
Your map should show the process from when a user needs clicks *sign-in* up to the point they are authenticated on the website. 
This should be a high-level overview of the process. 

You may use any diagramming software you'd like. [Diagrams.net](https://www.diagrams.net/) is free and open-source. 
Lucidchart (Limited Free Tier) and Microsoft Visio are also options (Visio can be downloaded for free from the Azure Education Portal).

Some time will be needed to research implementing Google's OAuth. You **do not** have to implement for this project.
