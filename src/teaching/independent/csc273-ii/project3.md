**Purpose:**
: Integrate an existing external account to provide authentication on a website.

### Description

You are to create a simple two page website: 1) First page will prompt the user
to login with their Google account and 2) a page for authorized users. 

All the work be done with front end development (HTML/JS), so no need for any
PHP. I recommend completing the work on ACAD. To create a website, you can
put HTML files under a directory called `public_html` in your home directory.

The second page for authorized users should display basic information about
their login. Users who haven't logged in should be directed to the first page 
to sign in.

Refer to this tutorial while working on the assignment:

Part 1: <https://www.intricatecloud.io/2019/07/adding-google-sign-in-to-your-webapp-pt-1/>
Part 2: <https://www.intricatecloud.io/2019/07/adding-google-sign-in-to-your-webapp-using-the-js-library/>
