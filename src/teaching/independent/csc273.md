## Course Information

**CSC273: Computing Systems Integration**

**Description:**
: This course focuses on the integration of information systems in organizations, which is the process
by which different computing systems and software applications are interconnected. It examines the 
strategies, methodologies, and implementation for combining interdependent systems, enabling two or 
more applications to interact and exchange data seamlessly. The course will explore various trends
in computing system integration, including Enterprise Resource Planning (ERP) software, cloud
computing, and mobile integration.

**Course Objectives:**
: **A** - Explain the concepts, objectives, and challenges related to the integration of information systems.
: **B** - Apply key system integration strategies and architectures.
: **C** - Assess common system integration tools.
: **D** - Analyze systems integration requirements. 
: **E** - Design feasible solutions for a systems integration problem.
: **F** - Apply systems integration technologies to implement system integration solutions.
: **G** - Describe Enterprise Resource Planning (ERP) software, including its business benefits and current solutions.
